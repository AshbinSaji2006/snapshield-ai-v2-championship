## Capture order

Run the four demo samples, capture result screens immediately, then capture Runtime, Privacy, Overview, and Incident center. Use the same packaged build and session so visual details remain consistent.

## Quality checks

- Text is legible at slide size; no tiny full-desktop captures.
- Actual provider and result values are visible and unedited.
- Synthetic inputs are labeled as synthetic in the surrounding slide or caption.
- File names, dates, and captions match the final deck.
- No image implies verified Snapdragon NPU execution unless the screenshot itself contains a valid QNN verification result from compatible hardware.
