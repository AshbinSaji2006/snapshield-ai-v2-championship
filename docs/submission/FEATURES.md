# Features

- Real UCI-trained local SMS spam classifier with untouched test report
- ONNX Runtime primary inference and scikit-learn fallback
- QDQ model and automated QNN/Snapdragon validation harness
- URL forensics without navigation, DNS, redirects, or HTTP
- Unicode/defanged/spacing evasion and controlled brand-domain mismatch detection
- Fully local RapidOCR screenshot text extraction
- OpenCV QR decode feeding the same URL/text engines
- Email, phone, Luhn card, IP, JWT, bearer/API token, password, and private-key detection/redaction
- Evidence contributions, suspicious spans, explanation, recommendations, and calibrated severity
- Sanitized SQLite incidents, detail view, analytics, and deletion
- Presentation mode and one-click real demo samples
- Truthful provider/hardware panel and separated component benchmarks
- Smoke-tested unsigned Windows one-folder package
