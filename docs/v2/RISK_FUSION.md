# Evidence-Aware Risk Fusion

SnapShield does not average model probabilities. Calibrated Fast/Deep probabilities decide routing and contribute one bounded model signal. Independent evidence is grouped into model, URL, brand, normalization, India-focused rule, privacy and social-engineering families, each with a documented cap. This prevents many low-value URL features from dominating by accumulation.

Two explicit corroboration rules add bounded elevation: credential/OTP solicitation combined with URL or brand evidence; and account-threat language combined with credential or payment requests. A lone evidence family is discounted. Low model probability discounts only weak totals below 28, so deterministic critical combinations remain effective.

The final 0–100 number is an ordinal evidence index used for severity bands: low below 25, moderate 25–49, high 50–74, critical 75–100. It is not a calibrated probability and is labeled as such in API/UI output.
