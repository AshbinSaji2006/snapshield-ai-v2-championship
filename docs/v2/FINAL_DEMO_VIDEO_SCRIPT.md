# SnapShield AI v2 — 3:30 demo video script

Record at 1920 × 1080, 100% browser zoom, with notifications disabled. Use the real packaged application and the bundled synthetic/inert demos. Trim load time; never fabricate a result.

## 0:00–0:15 — Promise

**Picture:** Command center.

**Narration:** “Suspicious content can be private. SnapShield AI analyzes messages, URLs, screenshots, and QR codes locally, so your data never needs to leave your device to protect your device.”

## 0:15–0:35 — Architecture

**Picture:** Architecture visual.

**Narration:** “A calibrated Fast Guard handles extreme-confidence cases. An adaptive router sends ambiguous or contextual cases to a compact Deep Guard. OCR, QR, URL, brand, PII, and security-rule evidence converge in a threat graph before an explainable risk and action.”

## 0:35–0:55 — Legitimate message

**Action:** Analyze the built-in Legitimate sample.

**Narration:** “A normal scheduling message stays low risk. The interface shows the local route, evidence, and timing instead of treating every urgent-looking phrase as malicious.”

## 0:55–1:25 — Phishing message

**Action:** Analyze Bank phish.

**Narration:** “This inert synthetic phishing message requests credentials and an OTP while creating urgency. SnapShield correlates social-engineering language, the claimed brand, and structural URL evidence, then recommends a safe next step. It parses the URL but never visits it.”

## 1:25–2:08 — Multimodal screenshot

**Action:** Analyze the built-in Screenshot sample; then open Explore graph.

**Narration:** “Now the same idea arrives as an image. RapidOCR extracts the text. OpenCV decodes the QR locally. The destination is displayed without navigation. Text, URL, QR, brand/domain, and rule evidence become connected nodes, making the final critical decision inspectable.”

## 2:08–2:28 — Live Shield and privacy

**Action:** Show Live Shield settings, then Privacy.

**Narration:** “Live Shield is off by default and needs explicit consent. It deduplicates and rate-limits clipboard checks, keeps alerts volatile, and saves an incident only when the user asks. Stored incidents contain hashes and derived metadata, not raw source content.”

## 2:28–2:55 — Evidence

**Picture:** Results slide.

**Narration:** “Deep Guard reached 94.44 percent recall on the 766-message UCI test and 98.04 percent on an independently sourced, strictly deduplicated 521-message external holdout. Adaptive routing reached a 0.30 percent UCI false-positive rate. These are named SMS dataset results—not universal phishing accuracy.”

## 2:55–3:18 — Snapdragon path

**Action:** Show Runtime.

**Narration:** “This machine verifies ONNX Runtime and CPUExecutionProvider. Provider abstraction, a QNN path, exact-artifact gating, a QDQ candidate, and AI Hub automation are implemented. Snapdragon NPU hardware validation is the next step; no NPU performance claim is made yet.”

## 3:18–3:30 — Close

**Picture:** Command center or closing slide.

**Narration:** “SnapShield AI: private AI, local security, designed for Snapdragon. Checking whether something is dangerous should not require giving it away first.”
