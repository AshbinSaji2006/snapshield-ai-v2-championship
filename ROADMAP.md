# Roadmap

1. Run the QDQ graph with CPU fallback disabled on named Snapdragon X hardware; retain QNN profiling proof and identical CPU/NPU comparisons.
2. Produce/test a native Windows ARM64 package, add per-launch API authentication, sign it, and design a secure installer/updater.
3. Add current, licensed, deduplicated email/phishing, multilingual, and screenshot datasets with isolated test sets and drift monitoring.
4. Improve OCR layout/low-resolution robustness and measure model-size/latency/accuracy tradeoffs on target hardware.
5. Add optional, consented reputation integrations without weakening the fully offline default.
6. Perform formal accessibility, concurrency/rate-limit, supply-chain, and native-parser security reviews before production use.
